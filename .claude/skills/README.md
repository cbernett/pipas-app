# Skills específicas do Pipas Labs

Use apenas a skill que corresponde à tarefa. Cada uma exige leitura dos documentos locais e inspeção do código atual; nenhuma substitui a documentação oficial Expo nem autoriza alterações fora do escopo do pedido.

Nos arquivos `SKILL.md`, caminhos `.claude/...` identificam documentação; caminhos como `src/...` e `modules/...` identificam arquivos-fonte relativos à raiz do repositório.

| Skill | Quando usar |
| --- | --- |
| [`block-workflow/SKILL.md`](block-workflow/SKILL.md) | Definir/adicionar/alterar bloco, workspace ou execução |
| [`android-native-module/SKILL.md`](android-native-module/SKILL.md) | Alterar módulo Kotlin, autolinking ou configuração nativa Android |
| [`sound-catalog-recording/SKILL.md`](sound-catalog-recording/SKILL.md) | Alterar catálogo, reprodução, captura, efeitos ou storage de sons |
| [`hardware-debugging/SKILL.md`](hardware-debugging/SKILL.md) | Investigar USB serial, evento de pad, comandos da placa ou falha física |
